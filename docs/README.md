# Документация cog_engine

`cog_engine` — движок на Rust, который порождает ответ **без авторегрессии**. Контекст сжимается в
матрицу быстрых весов (TTT). Рассуждение — это поиск траектории в непрерывном латентном
пространстве (JEPA + MPPI). Все токены ответа материализуются параллельно интегрированием ODE
(Continuous Flow Matching).

## Быстрый старт

```bash
git clone https://github.com/Artem101/AiAgent.git && cd AiAgent
cargo run --release -- demo                    # обучить ~4 мин на CPU, оценить, замерить скорость
cargo run --release --example quickstart       # то же самое из кода библиотеки
cargo run --release --example staged           # экскурсия по API по стадиям
cargo test                                     # 51 тест, включая «0 аллокаций» и паритет симулятора с Chromium
```

## Словарь

| Термин | Значение |
|---|---|
| **TTT** (Test-Time Training) | Слой, чьё «состояние» — это веса `W_fast`. На каждом токене они делают шаг градиентного спуска по самообучаемой функции потерь |
| `W_fast` | Матрица быстрых весов `d_fast × d_fast`, вся память о контексте |
| `S_prompt` | Вектор, прочитанный из `W_fast` после промпта (`PromptState`) |
| `s`, `s_0` | Латентное состояние рассуждения в `ℝ^{d_s}` (`LatentState`); `s_0` — начальное |
| `a` | Латентное действие, «шаг мысли», `ℝ^{d_a}`, компоненты в `[−1, 1]` |
| `P_φ` | World model: `s_{t+1} = P_φ(s_t, a_t)` |
| `ĝ` | Цель рассуждения, предсказанная goal head; служит `energy_target` для планировщика |
| `S_plan` | План — траектория `[s_0 … s_H]` (`LatentPlan`) |
| `H` | Горизонт планирования (число шагов мысли) |
| **MPPI** | Model Predictive Path Integral — сэмплирующий оптимизатор траекторий |
| **π** (policy prior) | Обученная политика `π(s, ĝ) → a`; её роллаут — тёплый старт для MPPI |
| **CFM** | Continuous Flow Matching — обучение векторного поля, переносящего шум в данные |
| `X_t`, `X_1` | Точка на пути «шум → эмбеддинги ответа» (`FlowState`); `X_1` — конец пути |
| **NFE** | Число вычислений векторного поля (Euler: `K`, Heun/Midpoint: `2K`) |
| **graph path** | Исполнение на операциях candle с autograd; на нём идёт обучение |
| **kernel path** | Собственные ядра на упакованных весах; на нём идёт инференс без аллокаций |
| **проба мыслей** | Линейная голова, которая читает латентное состояние как ответ (декодер действий и «озвучка» гипотез) |
| **копирование** | Указатели пробы на токены промпта: мысль переносит число или слово из страницы, вопроса или результата калькулятора |
| **BPE** | Байтовый токенизатор на 8192 токена (`models/tokenizer_ru.bpe`), обученный на «ru20k» и UD Russian |
| `CALC` | Действие агента «посчитать»: выражение уходит в `python3`, результат появляется в следующем наблюдении |
| **единая модель** | TTT + JEPA + декодер речи: одна сеть, которая и браузит, и считает, и разговаривает ([unified.md](unified.md)) |
| **декодер речи** | Каузальный трансформер единой модели: пишет действие или реплику по одному токену, читая план и токены контекста |
| `<user>`, `<bot>` | Спецтокены реплик разговора в наблюдении |
| **ru20k** | Датасет: 20 тыс. самых частых слов с примерами, грамматические вопросы, 910 тыс. диалогов |
